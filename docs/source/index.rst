Welcome to Training Stats Library's documentation!
====================================================

This library is a small, from-scratch example of docstring-driven Sphinx
documentation: every page under "Modules" below is generated straight from
the ``Args:``/``Returns:``/``Raises:`` docstrings in ``src/statlib`` via
``sphinx.ext.autodoc`` + ``sphinx.ext.napoleon`` (Google-style docstrings).
Update a docstring, rebuild, and the docs page updates -- no separate
documentation source to keep in sync.
